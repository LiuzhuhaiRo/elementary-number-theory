# 水桶排水问题 - MATLAB 解决方案

## 问题描述

现有一满桶水，桶底面直径为2m，高3m。现在其底面圆心处开一圆形小孔，直径为2cm，设水流出的速度v与水的高度h之间的关系为 v=√(2gh)，其中 g=9.8m/s²。

### 任务

1. **第一部分**: 求这桶水水面高度与时间的关系，并给出图示
2. **第二部分**: 若在开孔的同时，从桶口以500cm³/s的速度注水，求水面高度变化的规律

## 文件说明

## 理论推导

### 第一部分：仅排水

根据连续性方程和托里拆利定律：

1. **连续性方程**: A_桶 × dh/dt = -A_孔 × v
2. **托里拆利定律**: v = √(2gh)
3. **微分方程**: dh/dt = -(A_孔/A_桶) × √(2gh)

令 k = (A_孔/A_桶) × √(2g)，得到：

```
dh/dt = -k√h
```

分离变量并积分：

```
∫ dh/√h = -k ∫ dt
2√h = -kt + C
```

应用初始条件 h(0) = H₀：

```
h(t) = (√H₀ - kt/2)²
```

**水完全流出的时间**: t_empty = 2√H₀ / k

### 第二部分：排水 + 注水

考虑注水流量 Q_in = 500 cm³/s = 5×10⁻⁴ m³/s：

1. **水量平衡**: A_桶 × dh/dt = Q_in - A_孔 × v
2. **微分方程**: dh/dt = Q_in/A_桶 - (A_孔/A_桶) × √(2gh)

令 a = Q_in/A_桶，k = (A_孔/A_桶) × √(2g)，得到：

```
dh/dt = a - k√h
```

**平衡高度** (dh/dt = 0 时)：

```
h_eq = (a/k)²
```

该微分方程需要数值求解，程序使用 MATLAB 的 `ode45` 求解器。

## 结果分析

### 第一部分结果

- 桶的底面积: 3.141593 m²
- 孔的面积: 0.00031416 m²
- 水完全流出时间: 约 7824.6 秒 (130.4 分钟)
- 高度与时间关系: h(t) = (1.7321 - 0.000221t)²

### 第二部分结果

- 注水速率: 500 cm³/s = 5×10⁻⁴ m³/s
- 平衡高度: h_eq ≈ 0.129 m
- 由于注水速率远小于初始排水速率，水面将从 3m 逐渐下降到约 0.129m 的平衡位置

**物理意义**：
- 当水位高时，排水速率(∝√h)大于注水速率，水位下降
- 当水位降到平衡高度时，排水速率等于注水速率，水位稳定
- 平衡高度与注水速率的平方成正比

## 注意事项

1. 本解决方案假设水流为理想流体，忽略了粘性和湍流效应
2. 托里拆利定律 v=√(2gh) 假设孔口处的压力为大气压
3. 数值求解使用 `ode45` (龙格-库塔法)，精度较高
4. 如果使用 Octave，某些绘图函数可能需要调整
